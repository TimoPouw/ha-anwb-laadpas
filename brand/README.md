# Brand images

Upload the source logo here as `source.png` (square, preferably 512x512 or
larger, transparent background).

The integration icons are generated from it:

- `icon.png` (256x256)
- `icon@2x.png` (512x512)

These are the files a pull request to
[home-assistant/brands](https://github.com/home-assistant/brands) needs, in
`custom_integrations/anwb_laadpas/`.
